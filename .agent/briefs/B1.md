## Commands
Session = one persistent Chromium (headless default, `--headed` opt) launched by `start` with remote-debugging port; later commands reconnect via `connectOverCDP`; session state (ws endpoint, trace log) in OS temp dir `jev-browser/<session>.json` (default session `default`). `stop` closes.
- `start [--url U] [--headed] [--session S]`
- `goto <url>` · `observe [--full]` → `{url,title,elements:[...],omitted,text?}` (compact table: `e3 button "Submit" [testid=submit]`)
- Generic controls (planner micro-steps when needed): `click <ref>`, `type <ref> --text T | --input KEY`, `select <ref> <optionLabel>`, `check <ref> on|off`, `press <key>`, `scroll up|down`, `wait-for --text T | --testid X | --ms N (only if unavoidable)`, `eval --js "..."` (planner-authored only; recorded as `js` step).
  Every executed action is appended to the session trace as a SEMANTIC step (below), never a ref.
- `goal --file goal.json` → JEV loop in current session (or `--url` to start). goal.json: `{"goal": str, "startUrl"?: str, "inputs": {KEY: value | "${env:NAME}"}, "assertions": [...], "maxSteps"?: 25}`. Per step: snapshot → one JEV call (operation head over CLICK/TYPE_TEXT/SELECT/TOGGLE/SCROLL_DOWN/SCROLL_UP/WAIT/DONE/BLOCKED offering only ops with candidates; per-op target heads; `type_text_value` head = choice over input KEYS with key names + non-secret descriptions, never secret values) → execute only chosen head → re-check assertions in code. Done ⇔ all assertions pass (JEV DONE is only a hint: if DONE but assertions fail → one more step then blocked). Rules text = src1 NEXT_ACTION + TARGET verbatim from R4 (adapt TYPE_TEXT criterion: value comes from the named input key). Stuck: 3 consecutive no-page-change non-WAIT steps → blocked. Anti-loop: withdraw (op,target) after 3 repeats in last 8. Output: `{status: done|blocked|jev_unavailable|max_steps, steps, jevCalls, msTotal, failedAssertions?, trace}`.
- `save --name N [--assert file.json] [--dir D]` → re-run assertions on live page; only if pass, write scenario from session trace. Refuse if trace empty.
- `replay <name|path> [--base-url U] [--headed] [--dir D]` → fresh browser, run steps, check assertions, ZERO JEV calls (assert in code: replay path must not import/construct jev client). Output `{status: pass|fail, failedStep?, failedAssertions?, ms}`. Inputs `${env:NAME}` resolved at run; missing env → fail with clear message.
- `list [--dir D]` → scenarios `{name, goal, steps, recorded}`.
- `assert --file a.json` → check assertions on current page.

## Scenario format (`<repo>/browser-scenarios/<name>.json`, default dir = git root `browser-scenarios/`, `--dir` override)
```json
{"name":"...","goal":"...","startUrl":"/path or absolute","inputs":{"KEY":"literal or ${env:NAME}"},
 "steps":[{"op":"goto|click|type|select|check|press|scroll|wait_for|js","target":{"testid?":"","role":"","name":"","context":""},"input?":"KEY","text?":"","value?":"","state?":true,"key?":"","url?":"","js?":""}],
 "assertions":[...],
 "recorded":{"at":"ISO","by":"jev|manual","jevModel":"...","jevCalls":N}}
```
- Relative `startUrl`/`url` resolved against `--base-url` (so same scenario runs on localhost and Pages).
- Typed values: if came from input KEY → store `"input":"KEY"`; inputs whose value is `${env:...}` stay as placeholders; never write a resolved secret. Literal text typed via `--text` stored as literal.
- Resolution on replay: `testid` exact match wins (must be unique); else src2 scoring (role match/near-family, name exact +0.4 / substring +0.2 / token-Jaccard, context +0.15), threshold 0.7, ambiguity margin 0.06 → fail loud. Auto-wait up to 5 s (poll snapshot) before failing a step. No fixed sleeps.

## Assertions (code-evaluated, src2 set)
`url_contains`, `url_matches` (regex), `title_matches`, `text_contains`, `text_absent`, `element_exists` / `element_gone` (target as above), `value_equals`, `checked`, `count_at_least`, `console_errors_max` (count console errors since page load, optional `ignore` regex), `js` (expression must return true; allowed only in scenario/goal files). Empty needle = fail.
