## Product
Public GitHub repo, pitch demo of owner's (Benedek Molnár) original idea: JEV/TypeSafe typed primitives as neuron primitives:
- **Score** = graded membrane / dendritic potential (electrotonic, analog, leaky, time dimension)
- **Noul** = probability of spike (somatic threshold readout); sampled → all-or-none spike
- **Choice** = axonal collateral routing (which downstream target gets spike) / dendritic input gating
Pipeline: Score_t → Noul_t → spike_t → Choice_t → downstream Score_{t+1}. Spec must state the convo's correction: Noul ≠ spike, Noul = spike probability.

## ADDENDUM — CORS ruling (controller verified: OPTIONS → 400 "Disallowed CORS origin" for github.io AND http://localhost:8080). Overrides rulings 1 & 4 where they conflict.
Three modes (badge shows which):
- **SIMULATED** (default, GitHub Pages, no key): local seeded emulator, same response shape as real API.
- **REPLAY** (SHOULD): plays back `docs/data/jev-recording.json` — real JEV responses previously captured by presenter via proxy (recorded with fixed seed + stimulus sequence; contains NO key, NO headers; include model + timestamp + usage). Lets public visitors see genuine JEV outputs. Spec defines file schema, how to record (proxy `--record` flag or UI "Export recording" button in LIVE mode), and fallback when a request has no recorded match (nearest-key match rules, else simulated + "unrecorded" tag).
- **LIVE**: browser calls SAME-ORIGIN `/api/jev` served by bundled zero-dependency Node proxy `tools/jev-proxy.mjs` (Node ≥18, built-in fetch/http only, no npm install). Proxy: serves `docs/` statically AND forwards POST `/api/jev` → `https://api.typesafe.ai/v1/systemone`. Key resolution order: env `TYPESAFE_API_KEY` on proxy (preferred — key never reaches browser) → else browser-pasted key sent in header `X-JEV-Key` ONLY to same-origin proxy (sessionStorage default). Proxy binds 127.0.0.1 only, default port 8787, validates body (size limit 32 KB, question count cap, only POST JSON), strips/never logs key, adds no CORS headers (same-origin), enforces per-process rate limit + session budget, timeout 5 s, maps upstream errors. Page auto-detects proxy via GET `/api/health` (returns {ok, keySource:"env"|"none", model}) → LIVE available; on GitHub Pages health fails → LIVE disabled with tooltip explaining "run `node tools/jev-proxy.mjs`".
- Optional (MAY, documented only): Cloudflare Worker template `tools/cf-worker.js` with strict origin allowlist + key as Worker secret, for presenter who wants LIVE on a public URL; warn that it spends presenter's credits, require allowlist + budget cap.
- Real API facts (use exactly, from R3): POST https://api.typesafe.ai/v1/systemone, `Authorization: Bearer <key>`, body `{state, model:"jev-latest", questions:{<key>:{type:"noul"|"choice"|"score", instructions, criteria}}}`; score criteria = ARRAY of 2–10 ordered levels (dict → 422); choice criteria = map ≤255 options. Response `{model, answers:{<key>:{type, noul | choice+probabilities+confidence | score+legend+probabilities+confidence}}, usage}`. Errors 400/401/403/422/429/529. Warm latency ~0.26–0.29 s. Price ≈ $42 per 1B input tokens, output free. Read R3.md for exact JSON examples and copy them into spec.
Tests: e2e LIVE mode tested against proxy with upstream MOCKED (proxy `--mock-upstream` flag or Playwright route); node unit tests for proxy (key never logged, body cap, 127.0.0.1 bind, error mapping). Real-call smoke test gated on env `JEV_LIVE_TEST=1`.
